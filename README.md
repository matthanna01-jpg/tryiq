# tryiq

## NZ Gap Finder

An automated weekly research pass that looks for empty niches and underserved
needs in New Zealand — product/import gaps, startup/software gaps,
public-infrastructure gaps, and job-market shortages — and ranks candidates
by demand, supply gap, and feasibility.

- Methodology & scoring rubric: [`nz-gap-finder/METHODOLOGY.md`](nz-gap-finder/METHODOLOGY.md)
- Weekly digests: [`nz-gap-finder/reports/`](nz-gap-finder/reports/)
